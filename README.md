## 📖 Usage Guide

### Pairing
- Use `BT_SEL 0/1/2` to switch profiles.
- Use `BT_CLR` to clear current profile.

### Features
- **ZMK Studio**: Supported. Connect via USB to use the web editor.
- **OLED Display**: Enabled with battery, layer, and WPM status.
